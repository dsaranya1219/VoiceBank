# VoiceBank

Voice + face guided banking for blind and low-vision users. Supports English, Hindi, Kannada, Telugu and Tamil.

## Setup

```
pip install flask flask-cors gTTS pygame deep-translator noisereduce openai-whisper scipy opencv-contrib-python librosa sounddevice pyttsx3 numpy
```

## Run

```
python app.py
```

Then open http://127.0.0.1:5000
